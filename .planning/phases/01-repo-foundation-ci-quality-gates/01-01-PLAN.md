EXTRA-DEV RULE (binds every `uv run` in this plan, local and CI). Always write `uv run --extra dev <tool>`; never a bare `uv run <tool>`. `uv run` performs an implicit sync of the DEFAULT dependency set before executing, and `dev` is an optional extra rather than a default one — so a bare `uv run ruff ...` re-syncs the environment WITHOUT `dev` and uninstalls ruff, mypy and pytest from `path/to/venv` as a side effect of trying to run them. The next invocation reinstalls them, the one after removes them again. Passing `--extra dev` on every call keeps the implicit sync's target set identical to what `uv sync --extra dev` installed. Inside CI, where an explicit `uv sync --frozen --extra dev` step has already run, use `uv run --frozen --extra dev <tool>` so the lockfile is additionally enforced.

This mandate is LOCAL ONLY. Inside `.github/workflows/ci.yml` and inside `components/ingest/Dockerfile` there is no `path/to/venv` — CI and the image use their own interpreters (Python 3.12 via `.python-version`). Never reference `path/to/venv` from the workflow or the Dockerfile.
