## Design decisions carried in from plan 03-01

All five design decisions in `03-01-PLAN.md` bind this plan without restatement. In particular: uniform `@dsl.component(base_image=image_for(...))` style, no exception handling in component bodies, exactly one `lib` call per component body, `ingest`/`validate` as genuinely separate stages, and the `{version}/{stage}/{month}.parquet` backfill key.

Two additional decisions this plan locks:

1. **`dsl.If` without `dsl.Else`/`dsl.OneOf`.** REQ-B7 names "`dsl.If`/`dsl.OneOf`" as the mechanism family. This DAG uses `dsl.If` alone. `dsl.OneOf` exists to collect a value from both branches for a downstream consumer, and the only end-of-run consumer here is the `ExitHandler` exit task, which provably cannot consume outputs from tasks inside its own scope (`03-RESEARCH.md` Pitfall 11, `kubeflow/pipelines#10187`). Adding an else-branch component solely to feed an unconsumed `dsl.OneOf` channel would be ceremony. REQ-B7's acceptance criteria — a worse model does not call `register`, a better one does — are met by `dsl.If` alone, and the skipped condition group is the documented skip-branch REQ-B4 explicitly permits. Record this in the ADR section (plan 03-03).
2. **`parallelism` is a compile-time constant.** `PARALLELISM = 2` in `pipelines/train_pipeline.py`, not a pipeline parameter. See `03-01-PLAN.md`'s design note.

    DAG body, in order:

    5. After the loop closes, `merge_features(parts=dsl.Collected(features_task.outputs["features"]))`, hardened at 1Gi request / 2Gi limit. Referencing the loop task's output after the block is the documented fan-in form.
