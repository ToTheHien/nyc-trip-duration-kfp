## Design decisions this plan locks

Read before writing any component. These bind plans 03-01 through 03-05.

1. **Component style is uniform: `@dsl.component(base_image=...)` Python function components**, for all nine components. `03-PATTERNS.md` sketched per-component `main.py` argparse CLIs under a `@dsl.container_component` assumption; that assumption is superseded here. Reasons: `dsl.Collected` fan-in needs `Input[List[Dataset]]`, and the ExitHandler exit task needs `PipelineTaskFinalStatus` - both are Python-function-component-only surfaces, and one uniform style beats two. Everything else in `03-PATTERNS.md` (thin-wrapper discipline, exactly one `lib` call per component, boundary constraints, GHCR SHA tagging, pinned-SHA CI actions, the credentials-via-Secret rule) applies verbatim to `component.py` bodies.
2. **Component bodies never catch exceptions.** A `@dsl.component` that returns a non-zero int does not fail the task; only a raised exception does. Let `FileNotFoundError` / `ValueError` / pandera `SchemaError` / `MlflowException` / `botocore` errors propagate as a loud pod failure carrying the original message. This replaces `03-PATTERNS.md`'s `try/except -> stderr -> return 1` CLI idiom, matches `03-RESEARCH.md`'s Security Domain "let it propagate" guidance, and is what makes REQ-B9's deliberate-failure demo possible.
3. **`lib/` owns all file I/O, not just all pandas.** `scripts/check_component_boundary.sh` forbids `.read_parquet(` / `.to_parquet(` / a pandas or numpy import inside `components/`, so a component body physically cannot read or write a Parquet artifact. Every component therefore does exactly: an in-function import of one `lib.artifacts` / `lib.tracking` function, one call passing `Path(artifact.path)` values, then `artifact.metadata[...]` assignment. Nothing else.
4. **`ingest` and `validate` are genuinely two stages.** `lib.ingest.load_month` already performs both the D-09a row-level pre-filter and the pandera structural validation. Calling it from `ingest` would leave `validate` a no-op passthrough - a fake DAG stage. Instead `lib.artifacts.ingest_month_to_parquet` composes `read_month_chunked` + `add_trip_duration` + `filter_trip_quality` (re-emitting the same INFO record `load_month` emits, naming the month and every dropped count, so REQ-C1's "not silently" survives the split), and `lib.artifacts.validate_parquet` calls `lib.schemas.validate_trips`. `lib/ingest.py` itself is not modified.
5. **Deterministic backfill key format** is `f"{version}/{stage}/{month}.parquet"` in bucket `backfill`, with full-overwrite semantics - never append or merge. `version` is the `features_version` pipeline parameter introduced in 03-02, which doubles as REQ-B10's cache-invalidating input change.
