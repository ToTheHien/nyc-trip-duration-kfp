<environment>
All local Python/uv/pre-commit invocations go through `scripts/qa.sh` (created in plan 01-02), which resolves the repository root from its own path and exports `UV_PROJECT_ENVIRONMENT="$REPO_ROOT/path/to/venv"` when `CI` is unset, per CLAUDE.MD. Invoke `pre-commit` as `UV_PROJECT_ENVIRONMENT=path/to/venv uv run --extra dev pre-commit ...` — the `--extra dev` is mandatory on every `uv run` in this repository, because uv's implicit pre-run sync targets the default dependency set and a bare `uv run pre-commit` would uninstall pre-commit, ruff, mypy and pytest from the mandated venv as a side effect of running them, turning a break-cycle verdict into an unrelated tooling failure.

IMAGE TAG DERIVATION (established in plan 01-01, load-bearing for every proof in this plan). CI tags images `ghcr.io/<owner>/<repo>/ingest:${{ github.event.pull_request.head.sha || github.sha }}`. On a `pull_request` run that resolves to the PR BRANCH HEAD commit — a real commit you can `git cat-file -e` — not to `github.sha`, which on a PR event is the ephemeral `refs/pull/N/merge` SHA that exists only inside the run. Every SHA this plan records for an image-existence check must therefore be a branch head commit obtained from `git rev-parse HEAD` on the break branch (equivalently `gh pr view --json headRefOid`), never a merge-ref SHA and never a post-merge `git rev-parse HEAD` on the default branch.

`gh` is authenticated as `ToTheHien` with scopes `repo, workflow`. It has NO `read:packages` scope. If D-05 selected private packages, the pull proof in Task 2 requires a `read:packages` token the current credential set does not provide — in that case halt and surface the gap rather than skipping the proof.

This plan is `autonomous: false`. Both tasks end in a `<human-check>` requiring a person to open real GitHub Actions run pages and read them, and Task 2 Part 2 can halt on a blocked precondition under a private D-05. The execute-phase orchestrator must therefore pause for the developer at those points rather than treating the plan as fire-and-forget.
